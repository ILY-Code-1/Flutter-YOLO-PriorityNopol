Black Box Testing — PrioScan

Pengujian fungsional berbasis skenario untuk seluruh fitur PrioScan. Setiap use case diuji minimal dengan satu skenario sukses dan satu skenario gagal.

UC1 — Melihat Informasi Aplikasi
1Menampilkan beranda & cara kerja aplikasi 1. Buka aplikasi PrioScan — Tampil judul "Priority Vehicle Detection", logo, deskripsi, dan 3 langkah "Cara Kerja" Beranda tampil lengkap sesuai harapan PASSSkenario sukses
2Navigasi geser ke Riwayat dari beranda 1. Buka aplikasi
2. Tekan panah ke bawah		 — Berpindah ke halaman Riwayat Deteksi Halaman riwayat tampil PASSNavigasi antar halaman
UC2 — Mengambil Gambar Kendaraan
3Mengambil gambar via kamera 1. Tekan GET STARTED
2. Arahkan kamera
3. Tekan "Ambil Gambar"		 Kamera aktif, objek ambulans di layar Foto ter-capture & tampil pada kotak pratinjau, muncul tombol Ambil Ulang & SUBMIT Foto tampil pada pratinjau PASSSkenario sukses
4Kamera tidak tersedia (emulator/izin ditolak) 1. Tekan GET STARTED pada perangkat tanpa kamera/izin Izin kamera ditolak Kotak gambar kosong ditampilkan, aplikasi tidak crash Kotak loading/kosong tampil, app stabil PASSSkenario gagal (graceful)
UC3 — Mengunggah Gambar Kendaraan
5Mengunggah gambar dari galeri 1. Buka Deteksi
2. Tekan "Upload Gambar"
3. Pilih foto		 File foto_police.jpg Gambar tampil pada pratinjau, siap di-submit Gambar terpilih tampil PASSSkenario sukses
6Membatalkan pemilihan gambar 1. Tekan "Upload Gambar"
2. Tekan kembali tanpa memilih		 — Kembali ke pratinjau kamera, tidak ada gambar terpilih Tetap di pratinjau kamera PASSSkenario gagal/batal
UC4 — Mendeteksi Kendaraan & Plat Nomor
7Deteksi berhasil & tersimpan 1. Ambil/upload gambar
2. Tekan SUBMIT		 Gambar ambulans plat "B1234XYZ", koneksi internet aktif Indikator loading muncul, lalu pindah ke Hasil Deteksi: jenis "Ambulance", plat "B 1234 XYZ", confidence; data tersimpan di Firestore Hasil tampil & tersimpan PASSSkenario sukses
8Submit saat tidak ada internet 1. Matikan internet
2. Tekan SUBMIT		 Gambar valid, koneksi mati Snackbar "Tidak ada koneksi internet", tetap di halaman Deteksi Snackbar error tampil PASSSkenario gagal (SocketException)
9Submit dengan respons API lambat 1. Tekan SUBMIT
2. API tidak merespons > 30 detik		 Server lambat Snackbar "Koneksi timeout, coba lagi" Snackbar timeout tampil PASSSkenario gagal (TimeoutException)
UC5 — Melihat Hasil Deteksi
10Menampilkan detail hasil deteksi 1. Selesai deteksi / tap kartu riwayat Record confidence 0.93 Tampil gambar, jenis kendaraan, nomor polisi, badge "High" 93.0%, tanggal deteksi Detail tampil lengkap PASSSkenario sukses
11Badge confidence rendah 1. Buka hasil dengan confidence rendah confidence 0.45 Badge "Low" warna merah, persentase 45.0% Badge Low tampil merah PASSVariasi nilai (batas)
UC6 — Melihat Riwayat Deteksi
12Menampilkan riwayat terurut 1. Buka halaman Riwayat ≥ 2 record tersimpan Daftar kartu deteksi tampil, terbaru di atas Daftar terurut tampil PASSSkenario sukses
13Riwayat kosong 1. Buka Riwayat tanpa data Koleksi kosong Pesan "Tidak ada data untuk kategori ini" Pesan kosong tampil PASSSkenario gagal/kosong
UC7 — Memfilter Riwayat Deteksi
14Memfilter berdasarkan kategori 1. Buka Riwayat
2. Pilih "Police"		 Ada record Police & Ambulance Hanya kartu berjenis "Police" yang tampil Daftar terfilter Police PASSSkenario sukses
15Filter kategori tanpa data 1. Pilih "Fire Truck" Tidak ada record Fire Truck Pesan "Tidak ada data untuk kategori ini" Pesan kosong tampil PASSSkenario gagal/kosong
